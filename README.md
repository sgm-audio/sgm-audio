# SGM Audio

Scott Mills, Saskatoon, SK. Audio DSP, plugin and audio-AI work, plus REAPER scripts and the tooling I build around them.

What's here, roughly:

- Plugin and DSP experiments: state-space (Mamba-style) models running per sample in C++ and Rust, CLAP builds. Most of these are research code and aren't real time yet; each README says where it stands.
- MIDI 2.0 tooling.
- REAPER scripts, some distributed through ReaPack.
- AI tooling around audio production and my own workflow.

Each README should say what the code does, what's been tested and on what machine, and what's broken. If you find a claim the code doesn't back up, open an issue.

Licences are per repo, so check that repo's LICENSE file. Most are MIT and a few are Apache-2.0. steadyflow and MAAPS_Nexus_V1_V5 aren't open source.
