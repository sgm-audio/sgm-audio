# SGM Audio

**Audio DSP · Plugins · AI tooling** — by Scott Mills, Saskatoon, SK.

Real-time audio engineering software: Mamba-SSM audio plugins, MIDI 2.0 tooling, REAPER automation, and AI-assisted production tools.

## Featured projects

- **[midici](https://github.com/sgm-audio/midici)** — Rust MIDI-CI / Property Exchange responder stack for MIDI 2.0
- **[stem-midi-pro](https://github.com/sgm-audio/stem-midi-pro)** — guitar/bass stem separation (Mamba-SSM) + polyphonic MIDI transcription
- **[apc-mcp](https://github.com/sgm-audio/apc-mcp)** — MCP server for JUCE/CLAP/VST3/ARA plugin projects
- **[sgm-suno-workflow](https://github.com/sgm-audio/sgm-suno-workflow)** — REAPER pipeline for Suno AI exports → mix-ready projects
- **[tab-agent-pro](https://github.com/sgm-audio/tab-agent-pro)** — audio-to-tablature transcription
